Detailed Description

Integration test fixture for BallChaserNode.

Creates the BallChaserNode with a short lost_timeout_ms (200ms) for faster tests, a publisher node for synthetic images, and subscribers for /cmd_vel and /ball_chaser/state to verify outputs.
